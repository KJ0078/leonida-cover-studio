Leonida Cover Studio is an offline web app that turns your photos and a caption into multi-panel GTA-style cover art with a Vice City sunset/neon grade, exported as a PNG in common post sizes. Your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
